# MEME GENERATOR APP

## 🚀 About

A fun web application that allows users to generate memes by adding custom text to popular meme templates.  
Built with React  it fetches meme templates from an API and lets users make their creations.  



## ✨ Features
- ✏️ Add custom top and bottom text
- 🔄 Random meme template generator
- 📱 Fully responsive design


 ## 🛠 Tech Stack
- Frontend: React, CSS
- Deployment: Vercel

Live Demo 👉 [Meme Generator](https://meme-appp-ayush-rais-projects-22ebbee0.vercel.app/)


## ⚙️ Installation

# Clone the repo
```
git clone https://github.com/ayushrai26/Meme-Generator-App.git
cd meme

# Install dependencies
npm install

# Start development server
npm start

```
